Composition library

Geometry re-implemented from three Figma mockup sheets; background, shadow and tokens are this site's own. Grouped by platform, not by which sheet each came from — the source is noted on each card. Every card sits on the same neutral ground (bg-surface) so what varies is the layout: a composition is the site's grey with the product's screens on it, and the colour comes from the screens. Markup: comp comp--<family> comp--<id> comp--bg-<bg>.
